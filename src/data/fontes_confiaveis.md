# 🛠️ Arquitetura de Raspagem Automática com Firecrawl (https://github.com/firecrawl/firecrawl.git)

O **Firecrawl** é uma engine moderna de web scraping e crawling projetada especificamente para alimentar aplicações de IA/LLM com dados limpos. Ele converte portais complexos como Billboard, Pitchfork e NME em Markdown estruturado sem poluição de anúncios, paywalls ou cabeçalhos desnecessários.

### Core Endpoints do Firecrawl:
1. **`/v1/scrape`**: Raspa uma única URL e retorna Markdown limpo, HTML limpo, screenshot e metadados.
2. **`/v1/crawl`**: Raspa um portal inteiro recursivamente seguindo links de turnês e festivais.
3. **`/v1/map`**: Mapeia todos os sub-links de um site de música em segundos.
4. **`/v1/batch/scrape`**: Executa raspagem paralela de até centenas de notícias simultaneamente.

### Exemplo de Uso em Node.js / TypeScript:

```typescript
import FirecrawlApp from '@mendable/firecrawl-js';

const firecrawl = new FirecrawlApp({ apiKey: process.env.FIRECRAWL_API_KEY });

// Raspar notícia do Oasis Tour 2026
const scrapeResult = await firecrawl.scrapeUrl('https://www.billboard.com/music/concerts', {
  formats: ['markdown'],
  onlyMainContent: true
});

console.log(scrapeResult.markdown);
```

### Exemplo de Uso em Python:

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="YOUR_API_KEY")

# Extração estruturada de datas de shows
scrape_result = app.scrape_url('https://news.pollstar.com', params={
    'formats': ['markdown'],
    'onlyMainContent': True
})

print(scrape_result['markdown'])
```
